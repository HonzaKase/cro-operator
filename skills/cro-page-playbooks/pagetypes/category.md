# Page type: Kategorie / listing (PLP)

*Primární autorita: Baymard (21 000+ parametrů product-list) + NN/g.*

## Primární cíl
Umožnit **rychlou orientaci v katalogu a dovést na relevantní PDP** — bez choice overload. Listing rozhoduje, kolik produktů uživatel uvidí a jak rychle zúží výběr.

## Ideální struktura (sekce)
- **Subkategorie / mezistránky** — zobrazit zvlášť, nad listingem, oddělené od filtrů (NN/g: zvyšuje discoverability, snižuje overload).
- **Filtry** — desktop = strukturovaný sticky sidebar; mobil = **dedikovaný full-screen modál** (ne horizontální toolbar).
- **Sort toolbar** — min. 4 typy: Price, User Rating, Best-Selling, Newest.
- **Thumbnaily** — min. 3 na produkt (apparel 5–15), dost velké.
- **Listing entry** — „self-sufficient": název s charakteristikami, cena, barvy/varianty, rating (na mobilu „každý klik se počítá").

## Must-have + umístění
- **Robustní filtrování** — 5 esenciálních: Price, User Ratings, Color, Size, Brand (jen 49 % e-shopů má všech 5).
- **Kombinace hodnot v typu** (Blue OR Black) — logika **OR uvnitř facetu, AND napříč facety** (14 % to blokuje).
- **Applied-filters overview** — viditelné aktivní filtry, rychle odebratelné (20 % je neukáže).
- 4 sort typy (jen ~31 % má všechny) · varianty sloučené do jedné položky (42 % zaplevelí duplicitami) · 3+ thumbnaily (jen 20 % nabízí).

## Informační hierarchie
1. Subkategorie nad filtry (hrubé zúžení → jemné). 2. Filtry vždy dosažitelné (desktop sticky sidebar, mobil prominentní vstup). 3. Aktivní filtry viditelné/odstranitelné. 4. Listing entry self-sufficient. 5. Konzistentní grid (1 produkt = 1 položka).

## Nejčastější selhání + čísla (Baymard)
**58 % desktop / 78 % mobil** listing má „mediocre or worse" UX (2025) — mobil dramaticky horší · 68–69 % nenabízí všechny 4 sort typy · 51 % nemá všech 5 filtrů · 14 % neumí kombinovat hodnoty · 20 % neukáže aplikované filtry · 80 % bez 3+ thumbnailů · 42 % varianty jako separátní položky.

## Nejúčinnější fixy
Doplnit 5 filtrů + 4 sort typy · mobil full-screen filter modál s OR/AND + viditelný count · sloučit varianty · 3+ thumbnaily s hover/swipe · subkategorie nad listingem · applied-filters lišta.

## Clarity signály
Dead clicks na thumbnaily (čekaný hover/swipe / málo fotek) · rage/dead na filtrech (nejde kombinovat / neukazuje stav / horizontální toolbar) · excessive scrolling bez prokliku (entry nedává dost info) · rage na sort dropdownu (chybí potřebný sort) · quickbacks PDP→kategorie (slabý message-match listing→PDP).
