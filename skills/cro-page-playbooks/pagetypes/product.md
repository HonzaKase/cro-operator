# Page type: Produkt (PDP)

*Primární autorita: Baymard (115+ PDP guidelines, 30 000+ skórovaných PDP).*

## Primární cíl
Dát dost informací k **jistotě nákupu**, odstranit poslední pochybnost, a **bez tření dostat do košíku**. PDP musí současně prodat (vizuál), informovat (specs, scale), uklidnit (recenze, return, total cost), konvertovat (ATC nad foldem).

## Ideální struktura (sekce)
- **Nad foldem vlevo:** galerie + zoom (56 % uživatelů zkoumá fotky jako úplně první akci; mix plain / in-scale / close-up / lifestyle).
- **Nad foldem vpravo:** buy box — název, cena, varianty, ATC, klíčová reassurance (doprava/return/skladem).
- **Pod buy boxem:** varianty (velikost/barva) jako **tlačítka, ne dropdown** (57 % e-shopů chybně používá dropdown).
- **Středně:** popis + specifikace + **scale info** (42 % odhaduje velikost z fotek; 37 % nedává in-scale obrázek).
- **Níž:** recenze — rating + počet + fotky uživatelů + odpovědi na negativní (89 % neodpovídá na negativní; 63 % neumí navigaci ve fotkách recenzí).
- **Spodek:** total cost / doprava / return policy (60 % očekává return policy na PDP; 67 % nedává odhad dopravy).

## Must-have + umístění
ATC + cena **nad foldem**, vizuálně dominantní · **sticky ATC bar** (mobil/dlouhé PDP; uplift ~5–15 % ⚠️) · velikost jako tlačítka se stavem skladu · vysoké rozlišení + zoom (pinch/double-tap mobil) · rating + počet recenzí u fotek · in-scale + price-per-unit · save/wishlist bez nuceného účtu.

## Informační hierarchie
1. Vizuál vlevo, rozhodnutí vpravo (desktop). 2. **Cena a ATC nikdy pod fold** (nejčastější tichý zabiják). 3. Reassurance blízko ATC, ne v patičce. 4. Stav variant viditelný (ne skrytý v dropdownu). 5. Recenze/specs jako důkazní vrstva (uživatel scrolluje pro potvrzení už skoro učiněného rozhodnutí). 6. Total cost transparentní co nejdřív.

## Nejčastější selhání + čísla (Baymard)
**52 % desktop / 62 % mobil** PDP má „mediocre or worse" UX (2026) · 57 % dropdown místo tlačítek · 37 % bez in-scale · 25 % slabý zoom/rozlišení (~40 % bez pinch zoom mobil) · 89 % bez použitelného wishlistu · 81 % bez price-per-unit · 15 % opuštění kvůli return policy.

## Nejúčinnější fixy
Varianty → tlačítka se stavem skladu · cena+ATC nad fold + sticky · galerie 5–15 fotek + vysoký zoom · recenze blízko ceny + fotky uživatelů · return policy + odhad dopravy + total cost na PDP · in-scale + price-per-unit.

## Mobil vs desktop
Mobil horší UX (62 % vs 52 % mediocre) i vyšší abandonment (⚠️ agregátory uvádějí ~80–86 % na mobilu — ne Baymard, směrové). Mobil: pinch/double-tap zoom povinný, sticky ATC, velikost-tlačítka místo nativního selectu.

## Clarity signály
Dead clicks na hlavní fotku (čekaný zoom) · rage clicks na ATC (nevybraná varianta / disabled / pomalý feedback) · hluboký scroll k ceně/ATC (pod foldem) · scroll spike u recenzí (rozhodovací) · quickbacks PDP→kategorie (chyběla scale/specs/return → vrací se „shoppovat").
